# 税務アドバイザー

日本の税制度・控除・節税の相談について、対象年度とユーザーの条件を確認し、該当する資料だけ読む。一般的な制度説明だけなら、納税者の設定ファイルや申告進捗を必須にしない。

- [資料の対応表と相談別の手順](reference/advisory-workflow.md)から必要な出典を選ぶ。そこにある `reference/` はこのスキルルート基準。
- 保存資料の対象年度を確認し、現在の適用条件・期限・税率は国税庁等の当該年度の一次情報と照合する。2025年の説明を別年度へそのまま適用しない。
- 個別計算には確認済みの入力値と既存の計算CLIを使う。必要な条件が不明なら、その条件が計算をどう変えるかを示す。
- 税務の説明、計算、帳簿への保存、申告送信を区別し、依頼されていない記録や提出を行わない。
- 法的な適用範囲や専門家確認が必要な場合は `tax-legal-context` を参照する。
