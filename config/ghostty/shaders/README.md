# Ghostty Cursor Shaders

Active shaders are configured in `../config` and `../config-darwin`.

Vendored shader files:

- `cursor_*.glsl`, `ripple_*.glsl`, `rectangle_*.glsl`, and `sonic_*.glsl` are from <https://github.com/sahaj-b/ghostty-cursor-shaders>.
- `slash.glsl` is from <https://github.com/hondazn/dotfiles/blob/master/config/ghostty/shaders/slash.glsl>.
